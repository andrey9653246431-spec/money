# Master-промпт AI-иллюстрации

```text
Создай одну вертикальную editorial-иллюстрацию 1080×1350 для канала о повседневных финансах «Деньги без паники».

ТЕМА: [ТЕМА]
СЛОТ: [утро / день / вечер / финансовый гороскоп]
СЮЖЕТ: [ОДНА КОНКРЕТНАЯ СЦЕНА]

Единый стиль: современная плоская иллюстрация с лёгкой бумажной фактурой, чистые геометрические формы, профессиональная журнальная композиция. Палитра: тёмно-синий #16324A, мятный #B8E3D2, кремовый #FFF5E6, мягкий оранжевый #FFB46B, небольшой коралловый акцент #F17C67.

Один понятный визуальный центр, спокойный фон, ощущение контроля и здравого смысла. Сохрани спокойное свободное пространство в верхней трети для последующей вёрстки, но не добавляй туда текст.

Для утра — лёгкая абсурдная бытовая сцена о деньгах, без грубого юмора. Для дня — лупа, чек-лист, весы, корзина или смартфон как метафора проверки. Для вечера — уютный свет, луна, чашка чая, телефон и спокойный дом. Для гороскопа — звёзды и тонкий круговой орнамент, без текста.

Запрещено: любые буквы, цифры, надписи, логотипы, водяные знаки, реальные банковские карты, документы, бренды, криптовалютные символы, паника, роскошь, обещания богатства, агрессивные графики, фотorealistic лица, лишние пальцы и мелкие детали интерфейса.

Результат: одно самостоятельное изображение, без коллажа, рамки и макета телефона.
```

## Правило использования

AI-иллюстрация не заменяет фактчекинг поста. После генерации человек проверяет композицию, артефакты, отсутствие текста/брендов и соответствие смыслу. Генератор не должен создавать несколько вариантов внутри одного изображения или автоматически публиковать результат.
