# Changelog

- Генератор карточек 1080×1350 для morning/day/evening.

- Кириллический variable-шрифт Manrope и OFL-лицензия.
- JSON-валидация, защита от текстового переполнения, SHA-256 manifest.
- Генератор аватара 1024×1024.
- Промпты арт-директора и AI-иллюстрации.
- Автотесты, GitHub Actions и Dependabot.
