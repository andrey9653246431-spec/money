# Участие в проекте

1. Создайте ветку от `main`.
2. Для визуального изменения приложите до/после и собранные примеры.
3. Запустите `ruff check .`, `pytest` и `dbp-design build -i examples/posts.json -o dist`.
4. Не добавляйте секреты, личные данные и `dist/` в Git.
5. Новые ресурсы принимаются только с понятной лицензией и записью в `THIRD_PARTY_NOTICES.md`.
6. Не изменяйте финансовый смысл примеров ради визуального эффекта.

Для изменения схемы JSON одновременно обновите модель, JSON Schema, пример, README и тесты.
