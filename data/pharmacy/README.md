# Прайс аптек для бота

Файл `prices.csv` заполняется вручную (или скриптом из вашей выгрузки). Бот не обращается к сайтам аптек.

Колонки: `pharmacy,address,name,form,price,in_stock,otc,updated_at`.

- `otc` = 1 только для безрецептурных препаратов; остальные строки пропускаются.
- `updated_at` в формате ГГГГ-ММ-ДД. Бот показывает дату, на которую записана цена.
- Цены старее нескольких дней лучше не публиковать: обновляйте файл регулярно.
