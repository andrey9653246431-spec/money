# Бот сравнения цен — подробная инструкция

Telegram-бот для канала «Не переплачивай»: сравнивает цены в топ-10 супермаркетах РФ, собирает корзину и формирует список покупок, который можно отправить себе в Telegram (сообщением или файлом) или на email.

## Что умеет бот

- **Сравнение цен**: напишите название товара (или `/search молоко`) — бот покажет цены по каждому доступному магазину, цену за кг/литр и акции, самый дешёвый вариант отмечен 🏆.
- **Корзина**: добавление кнопками из результатов поиска, изменение количества, удаление, итоги по магазинам и общий итог, кнопка «Самый дешёвый вариант» (пересчёт всей корзины по магазинам).
- **Список покупок**: из корзины — текст и файл `shopping_list.txt`, отправка в чат; отправка на email — после настройки SMTP (см. раздел про email).
- **Магазины**: `/stores` — какие сети доступны по точке доставки.

## Источники цен (честно)

- **Купер** (бывший СберМаркет) — живые цены и акции по неофициальному API. Покрытие зависит от точки доставки: в Москве по умолчанию доступны 7 из 10 сетей (Пятёрочка, Перекрёсток, Магнит, Лента, Ашан, Метро, Дикси). Верный, Спар и Окей в этой точке недоступны — бот так и пишет. Точку можно сменить переменными `BOT_LAT`/`BOT_LON`.
- **Едадил** — требует авторизации через Яндекс SSO, анонимный доступ недоступен (проверено). Поэтому акции берутся из Купера (скидки и старые цены видны в результатах). Провайдер Едадила в коде есть как заглушка с объяснением.

API Купера неофициальный и может меняться — если поиск перестанет работать, бот честно напишет об ошибке, а не выдумает цены.

## Шаг 1. Бот в Telegram: новый или существующий

**Можно использовать существующего `@ne_perepl_bot`** — один бот может и публиковать посты в канал, и отвечать на запросы о ценах. Публикатор только отправляет сообщения и не читает обновления, поэтому конфликтов не будет. Это даже лучше для бренда: подписчики канала находят бота в том же месте.

Отдельный новый бот нужен только если хотите полностью изолировать ценовой сервис (например, чтобы сбой бота не остановил публикации). В этом случае создайте его через **@BotFather** → `/newbot` и скопируйте токен вида `123456789:AA...`.

**Важно перед запуском:** у бота не должно быть активного webhook (иначе `getUpdates` вернёт 409 Conflict). Проверить: откройте в браузере `https://api.telegram.org/bot<токен>/getWebhookInfo` — в ответе `"url"` должно быть пустым. Если там есть URL — удалите его: `https://api.telegram.org/bot<токен>/deleteWebhook`.

## Шаг 3. Secrets и Variables

**Settings → Secrets and variables → Actions**:

Secrets:

```text
PRICE_BOT_TOKEN — токен бота из шага 1.
Если используете существующего @ne_perepl_bot, этот Secret можно не создавать:
бот сам возьмёт токен из уже существующего TELEGRAM_BOT_TOKEN.
```

Variables:

```text
PRICE_BOT_ENABLED = false   (сначала выключено)
BOT_LAT = 55.68             (необязательно: широта точки доставки)
BOT_LON = 37.75             (необязательно: долгота)
```

## Шаг 4. Первая проверка вручную

1. Откройте **Actions → Price comparison bot → Run workflow** (`session_minutes` — 5 для быстрой проверки).
2. В логах должно быть `Бот запущен` и `Сессия завершена`.
3. Напишите своему боту в Telegram `/start`, затем `молоко`.
4. Проверьте: сравнение цен, кнопка «в корзину», корзина, список покупок, отправка файлом.

## Шаг 5. Включить расписание

Установите `PRICE_BOT_ENABLED=true`. Бот работает сессиями: каждый час запускается и живёт ~50 минут (`cron: 0 * * * *`), затем завершается и сохраняет offset и корзины в `state/bot/`. Сообщения, пришедшие между сессиями, не теряются — бот подхватит их при следующем запуске.

## Как устроено внутри

```text
Telegram getUpdates (long polling, offset в state/bot/offset.json)
  → price_bot/bot.py (команды, кнопки, корзина, список)
  → price_bot/kuper.py (Купер API: магазины + поиск, curl_cffi)
  → price_bot/store.py (корзины и состояния в state/bot/*.json)
  → price_bot/mailer.py (email, только при настроенном SMTP)
```

Корзины хранятся по `user_id` в `state/bot/baskets.json` и коммитятся workflow после каждой сессии.

## Email (позже, когда будет ящик)

Сейчас отправка на email выключена — бот честно пишет «Email пока не настроен». Чтобы включить:

1. Создайте пароль приложения у почтового провайдера:
   - **Яндекс.Почта**: Настройки → Безопасность → Пароли приложений → создать пароль; хост `smtp.yandex.ru`, порт `465`.
   - **Gmail**: Аккаунт Google → Безопасность → Пароли приложений (нужна двухфакторка); хост `smtp.gmail.com`, порт `465`.
2. Заполните Variables: `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_FROM`, `SMTP_TO` (куда слать список). Пароль — в Secret `SMTP_PASS`.
3. В боте: корзина → «В список покупок» → «✉️ На email».

## Бот 24/7 (вместо сессий GitHub Actions)

Сессии GitHub Actions бесплатны, но бот не онлайн круглосуточно. Для постоянного онлайна:

- **Свой компьютер/сервер**: `pip install -r price_bot/requirements.txt`, затем `PRICE_BOT_TOKEN=... BOT_SESSION_MINUTES=100000 python -m price_bot.bot` (большое значение = работает без остановки).
- **Render / Fly.io / PythonAnywhere**: создайте сервис, укажите команду запуска `python -m price_bot.bot`, задайте `PRICE_BOT_TOKEN` и `BOT_SESSION_MINUTES=100000` в переменных окружения. GitHub Actions workflow при этом можно выключить (`PRICE_BOT_ENABLED=false`), чтобы не было двух экземпляров.

## Если что-то пошло не так

| Симптом | Причина | Что делать |
|---|---|---|
| В логах `ERROR: нет PRICE_BOT_TOKEN` | Secret не задан | Добавьте `PRICE_BOT_TOKEN` в Secrets |
| Бот не отвечает | Сессия не запущена / `PRICE_BOT_ENABLED` не `true` | Запустите workflow вручную или включите переменную |
| «Поиск временно недоступен» | Купер отклонил запрос (403) или API изменился | Подождите и попробуйте снова; проверьте логи |
| В результатах не все 10 сетей | Точка доставки | Смените `BOT_LAT`/`BOT_LON` под свой район |
| Кнопка «в корзину» пишет «устарела» | Поиск был давно, результаты перезаписаны | Выполните поиск заново |
| Дубли сообщений после паузы | Две сессии одновременно | Concurrency в workflow это исключает; проверьте, что не запущены два хостинга |
