# Интеграция с контент-заводом

## Два независимых визуальных трека

1. **Фирменная карточка Pillow** — детерминированный PNG с заголовком и пунктами. Работает локально без API-ключей. Это основной трек MVP.
2. **AI-иллюстрация** — создаётся внешним провайдером по `image_prompt`. Провайдер в репозиторий намеренно не встроен: ключи, тарифы и условия выбирает владелец. После генерации изображение проходит ручной review.

Не смешивайте их без правила: для каждого поста заранее выберите `visual_type=template` или `visual_type=ai`. В текущем JSON тип не хранится, потому что CLI строит только template-карточки.

## Последовательность

```text
Текстовый JSON → art-director.md → card JSON → validate → build
→ ручной визуальный review → редакторский approval → публикация
```

1. Сохраните результат текстового завода.
2. Обогатите каждый пост объектом `card` через промпт `prompts/art-director.md` или вручную.
3. Выполните `dbp-design validate --input content.json`.
4. Выполните `dbp-design build --input content.json --out dist/YYYY-MM-DD`.
5. Проверьте PNG и `manifest.json`.
6. Передайте в публикационный сервис только утверждённые файлы.

## Почему отдельный `card`

Полный пост может содержать 1200 знаков, ссылки и условия. Переносить всё на изображение нельзя. `card` — короткая визуальная выжимка, а оригинальный текст остаётся основным источником смысла. Генератор карточки не должен пересказывать финансовые факты самостоятельно.

## Manifest

`manifest.json` связывает `content_id`, имя файла, размеры, alt-текст, AI-промпт и SHA-256. Публикационный сервис должен хранить `content_id + platform` как уникальный ключ, чтобы повторный запуск не создал дубль.

## Ручной визуальный checklist

- заголовок читается на экране телефона;
- нет обрезанных строк и переполнений;
- пунктов не больше трёх;
- карточка не меняет смысл полного поста;
- нет логотипов и чужих товарных знаков;
- alt-текст соответствует изображению;
- изображение не содержит непроверенных цен и обещаний;
- рекламные обозначения, если требуются, проверены ответственным человеком отдельно.
